Meanwhile gtag.js itself is still fetched from googletagmanager.com (:7-8) before any consent is resolved.

(b) Decide the site should not load or configure GA before consent at all, and remove the pre-consent gtag.js fetch plus the throw: consent gate, then load.
(c) Leave analytics effectively off and remove the dead code and docs that claim otherwise.
