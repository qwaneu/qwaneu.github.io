Why it matters: initial-scale below 1 shrinks the whole page's default text size on first paint, on every page that uses this layout (11 files). Users can still zoom (maximum-scale=5.0), so this is not a zoom lock — it is a default-text-size problem, and it is easy to compensate for with bigger fonts instead of fixing.

Likely fix: `width=device-width, initial-scale=1`. Then re-check the pages that use this layout, because the 0.86 was probably a workaround for something overflowing — the overflow deserves its own yak rather than a scale hack. Suspects: services-grid-mobile and ribbon-narrow-mobile.
